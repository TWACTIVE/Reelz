Reelz

Recreate any Instagram Reel using your own camera roll clips — local CLI, no login required.

Quick Start

# 1. Clone the repo
git clone https://github.com/twactive/Reelz.git
cd Reelz

# 2. Install dependencies
brew install yt-dlp ffmpeg
pip install -r requirements.txt

# 3. Set your Anthropic API key
export ANTHROPIC_API_KEY=sk-ant-...

# 4. Run
python recreate_reel.py "https://www.instagram.com/reels/XXXX/" \
  --clips ./my_camera_roll

What it does

  1. Downloads the Reel via yt-dlp
  2. Detects every scene cut with ffmpeg
  3. Extracts the audio track
  4. Describes each shot using Claude vision
  5. Indexes your camera roll clips (cached — only new files re-tagged)
  6. Matches each trend slot to your best-fitting clip
  7. Assembles a rough-cut MP4 with trend audio overlaid
  8. Prints a slot-by-slot summary with alt clips for manual swaps

Dependencies

python 3.10+ yt-dlp ffmpeg anthropic

Output lands in output/recreated_reel.mp4. Camera roll index cached in clip_index.json — re-runs only process new files.
